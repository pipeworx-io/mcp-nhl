# mcp-nhl

NHL MCP — live NHL data via the official NHL API

Part of the [Pipeworx](https://pipeworx.io) open MCP gateway.

| Tool | Description |
|------|-------------|

## Quick Start

Add to your MCP client config:

```json
{
  "mcpServers": {
    "nhl": {
      "url": "https://gateway.pipeworx.io/nhl/mcp"
    }
  }
}
```

Or use the CLI:

```bash
npx pipeworx use nhl
```
